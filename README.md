# Workout Log

An installable workout tracker for a 4-day muscle-building plan. It logs sets, flags when to add weight, has a rest timer, and charts your progress. It works offline, and each person's history is saved on their own phone.

## Install on a phone
- **iPhone (Safari):** open the link, tap Share, then tap **Add to Home Screen**.
- **Android (Chrome):** open the link, tap ⋮, then tap **Install app** (or **Add to Home screen**).

## Backups
Go to **Plan → Backup → Save backup file** to save a backup. On a new phone, use **Restore** to bring your history back.
